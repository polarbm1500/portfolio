# 要件定義書

## 1. プロジェクト概要

- 背景: 自分が学んできたAI技術や実際に作ったものをまとめ、AIエンジニアとしてのスキルや経験をわかりやすく伝えるための手段
- 目的: AIエンジニアとしてのスキルや開発実績をわかりやすく伝え、仕事や案件の獲得に繋げることができる
- スコープ:
  - 含むもの
    - 自己紹介
    - スキル：デザイン・コーディング、フロントエンド、バックエンド、その他
    - 作成したもの
    - コンタクト
  - 含まないもの
    - 個人情報などの非公開情報
    - 実務で公開できない情報
    - ポートフォリオと関係のない作成物

## 2. ユーザーストーリー

- As a 採用担当者
- I want 求職者として自分のスキルや制作実績を掲載
- So that エンジニアとして次のステップに進める

## 3. 機能要件

| ID | 機能名 | 説明 | 優先度 | Phase |
|---|---|---|---|---|
| F-01 | プロフィール表示 | 自己紹介・自分の画像・経歴・AIエンジニアとしての目標を表示 | 高 | MVP |
| F-02 | スキルの表示 | デザイン・コーディング、フロントエンド、バックエンド、その他に区分して表示 | 高 | |
| F-03 | 制作実績表示 | 開発したAIアプリやWebアプリを一覧表示 | 高 | MVP |
| F-04 | 詳細表示 | 各作成物の概要・使用技術・工夫した点を表示 | 高 | MVP |
| F-05 | GitHub連携 | GitHubのリポジトリへのリンクを掲載 | 高 | MVP |
| F-06 | デモサイト表示 | 実際に動作するアプリへのリンクを掲載 | 高 | |
| F-07 | お問い合わせ | 仕事・案件の依頼や連絡ができるフォームを設置 | 高 | MVP |
| F-08 | レスポンシブ対応 | PC・スマートフォンの両方で閲覧可能 | 中 | |

## 4. 非機能要件

- パフォーマンス: ページ読み込み 3 秒以内
- セキュリティ: HTTPS通信、フォームの入力内容を適切に保護
- 可用性: 常時閲覧可能な状態
- レスポンシブ：PC・スマートフォンに対応
- 保守性：作成実績やスキルを簡単に追加、更新できる

## 5. 制約条件

- 予算: 無料枠で完結
- 期間: 2 週間
- 技術: Next.js + Vercel
- DB: 使用しない
